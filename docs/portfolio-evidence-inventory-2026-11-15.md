**Method:** The first three Pi-hole images were recovered from an earlier sanitized ZIP file. Their Git blob SHA-1 values exactly matched those returned for the public GitHub repository tree, so they correspond to the **published bytes**, not just screenshots that look similar. I inspected the displayed image content and identified the visible labels above. The local dashboard image had a different hash and size, so I **did not** treat it as evidence that the public dashboard was reviewed.

**WSL2 audit method and remediation:** On November 15 I verified the five originals by exact Git blob SHA-1 matches against the uploaded repository ZIP, visually inspected them and checked that none contained EXIF metadata. I found a recurring local account identifier in terminal prompts, ownership entries, the window title and one home path; no passwords, API tokens or private keys were seen. On **November 16**, I placed opaque redaction masks over those personal account portions in **all five original photo captures**, preserving evidence-bearing commands, file modes, socket endpoints, warning output and HTTP results. I then replaced all five GitHub JPEG paths in one commit (`3a909c31a17892e01b6e2036bbe1d23787791eac`). Every new blob SHA-1 matched the locally generated redacted file and was confirmed in GitHub's current `main` tree. WSL2/internal IP addresses and the generic system hostname remain visible as diagnostic context; no public routable home address was disclosed in these images. I did not invent or recreate terminal output. **The former versions remain recoverable through Git history** unless history is separately rewritten; this remediation hardens current image paths rather than guaranteeing historical erasure.

**Review progress — November 16 baseline and additions:** The original **10 of 10** public image files were inspected and hash-verified: four Pi-hole screenshots, five redacted WSL2 screenshots and the replacement VirtualBox cover. Five more monitoring images were subsequently published and matched to reviewed, privacy-checked copies, bringing the **current-file inventory to 15 of 15**. The later review is scoped to the visible content and current Git blobs, not a reinspection of every historic revision or a comprehensive accessibility audit. Earlier original WSL2 images and a prior VirtualBox cover remain in Git history.
